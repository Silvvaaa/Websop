# Websop

A small clothing web shop front end built with React.

## Features

- Product collections and category directory pages
- Sign-in / sign-up with Firebase Authentication
- Routing with React Router
- Styling with SCSS

## Tech stack

React 17, React Router 5, Firebase 9, SCSS (Create React App)

## Run locally

```bash
npm install
npm start
```

The app opens at http://localhost:3000. A Firebase project config is required for authentication (see `src/firebase`).
